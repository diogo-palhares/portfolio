## Context

At CI&T I work on AWS infrastructure for critical systems. Those systems needed better visibility: faster incident detection and wider monitoring coverage.

## What I did

- Built and operated an observability platform on AWS EKS with Grafana, Prometheus, Loki, Kafka, Grafana Alloy and Fluent Bit.
- Wrote Python sidecar containers for log processing and custom metric collection.
- Led the migration of the observability stack to another AWS region, rebuilding the EKS cluster in the process.

## Results

- Faster incident detection and broader monitoring coverage across critical systems.
- Less downtime during failover scenarios after the regional migration, and a more resilient platform overall.
